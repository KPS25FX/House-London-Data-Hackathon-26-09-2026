    See the voice test chart and full findings

    Test 1: Do residents feel the pressure outsiders feel?

    Each dot is a seat with measured polling. Across: home-seekers the local market can't house, per 1,000 residents (outside demand). Up: share of residents who say their neighbours worry about housing (the voters). Dashed lines split seats into thirds; the corners are the area types on the map.

    Test 2: Does building follow demand, or residents?

    Each finding compares the top and bottom thirds of seats. Building is measured per existing home, so large and small seats compare fairly.

    The decision each area type calls for

    An MP backs more homes when the voters who reward it outweigh the voters who punish it. Market demand says whether homes would actually get built; resident concern says which way the MP's own voters lean.

      7 · Data

      Manage the shared data

      Editors only. Import new seat figures or time series, or reset the database from the built-in snapshot.

      Editors only

      Data back end

      Changes here update the tool for everyone viewing it.

      Import seat data

      A JSON array of objects, each with code (ONS constituency code) plus any fields to update, e.g. [{"code":"E14001312","homes":412,"V":0.21,"vEst":false}]. Use it to load Datahub completions or the full Forest polling.

      Import time series

      A CSV in the London Datastore long format: dataset, area_code, area_name, area_type, period, year, measure, breakdown, value, unit, source. Each measure and breakdown becomes a trend everyone can chart and map. Borough rows and the London row are used.

      Policy evidence

      Edit the wording behind the Evidence page: evidence strength, what past policy shows, guardrails, who acts. Download the current set, edit the JSON, and import it. Fit and risk ratings stay calculated from the data.

      Reset from snapshot

      Writes the page's built-in seats, borough data, policy library and settings to the database. Use once to set up, or to undo a bad import. Saved memos are kept.
